## Common incidents

### "App returns 500s"
1. Check App Insights → Failures for the stack trace.
2. If a recent deploy — roll back (see above).
3. If database — check Azure SQL health in portal; check connection string secret in Key Vault.
4. Escalate to owner if unresolved in 30 minutes.

### "App is slow"
1. App Insights → Performance — which endpoint / query?
2. Check App Service metrics — CPU, memory. Scale up if capacity.
3. Check Azure SQL DTU / vCore — is the DB maxed?
4. If query-level: use App Insights dependency tracking to find the slow one, grab the SQL, run EXPLAIN in SSMS, add index if warranted.

### "Users can't log in"
1. Check App Service Easy Auth config in Azure portal.
2. Azure AD health — any outage at service health?
3. Check the user's group membership — were they removed recently?
