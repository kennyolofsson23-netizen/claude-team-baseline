Phase 2 — Enterprise license
Zero trust for AI output
Every Claude tool call (file read, bash command, web fetch) is intercepted by a hook before execution. Claude cannot self-grant permissions — the allow-list is set by the architect and enforced by the runtime, not by Claude itself.
Secrets stay out of the model
Pre-commit hooks block .env, private keys, and detected credential patterns before they reach git. CI re-runs gitleaks on the full branch history so no previous commit can sneak through on a rebase.
Off-stack code is blocked, not warned
If a junior asks Claude to install React, use MongoDB, or add requests instead of httpx — Claude is denied at the shell level, not just verbally. The deny list covers write access to .tsx, .jsx, .vue, and package.json.
CISO escalation path
Any stack change, new SaaS dependency, or data-classification rule requires explicit ARB approval. Documented in the change-approval matrix. No silent drift.
Audit logging (Phase 2)
PostToolUse hook ready to POST every Claude tool call to a logging endpoint (Splunk / Datadog / internal table). Activates with the Enterprise license alongside managed settings.
